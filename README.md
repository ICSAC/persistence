# Persistence

An index of the articles in *Persistence*, the journal of the Institute for Complexity Science and Advanced Computing (ICSAC): each article's page, DOI and PDF on icsacinstitute.org, and the link to the code and data behind it.

This repository holds links only. Each author keeps their code and data wherever they choose, and ICSAC links to it. ICSAC doesn't host, run or maintain the linked material, and nothing here is a copy of it. The PDF links go to the ICSAC edition of each article (one cover page in front of the author's unchanged manuscript), or to the author's original where there is no ICSAC edition.

The table is generated from the journal's article registry, the same record each article page on [icsacinstitute.org](https://icsacinstitute.org/journal/) is built from. Please don't edit it by hand: send corrections to help@icsacinstitute.org.

Each link is checked whenever the index is regenerated. A link that can't be reached is marked "Couldn't reach" and stays listed.
