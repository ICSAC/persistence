# Persistence: code and data index

Links to the code and data behind each article in *Persistence*, the journal of the Institute for Complexity Science and Advanced Computing (ICSAC).

This repository holds links only. Each author keeps their code and data wherever they choose, and ICSAC links to it. ICSAC doesn't host, run or maintain the linked material, and nothing here is a copy of it.

The table is generated from the journal's article registry, the same record each article page on [icsacinstitute.org](https://icsacinstitute.org/journal/) is built from. Please don't edit it by hand: send corrections to help@icsacinstitute.org.

Each link is checked whenever the index is regenerated. A link that can't be reached is marked "Couldn't reach" and stays listed.
